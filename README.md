# Kasa biletowa Term Maltańskich – demo

Pokazowa kasa samoobsługowa (Avista) dla Term Maltańskich w Poznaniu: strefa → czas pobytu → osoby → płatność kartą lub BLIK → bilet z kodem QR.
Ceny i godziny otwarcia są przykładowe; aplikacja nie łączy się z żadnym systemem.

**Demo online:** https://mateuszpietruniewicz-arch.github.io/termy-maltanskie-kasa-demo/

Na pokazie: otwórz link w Chrome i naciśnij **F**, żeby włączyć pełny ekran (ekran poziomy 4:3, obsługa dotykiem lub myszką).
